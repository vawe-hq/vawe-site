# Inspiration inside the system

Sites that already work in this register: a black ground, a grotesk plus a mono, one accent, dense
technical content, motion or video as the product. Read on 2026-11-22. From each we take one layout idea
per section type. We take no font and no colour from any of them; every idea is rebuilt with the tokens
in `SYSTEM.md`.

Fetch notes: vercel.com, motion.dev's nav, resend.com and unicorn.studio returned too little text to
use; ghostty.org's home returned only its name, so its docs page stands in.
